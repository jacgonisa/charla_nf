### 3. Script Update (`scripts/18-analyze_sco_nco_comparison.py`)

#### New Function: `extract_segment_info_from_bed()`

Parses BED file and extracts:

```python
def extract_segment_info_from_bed(bed_file):
    """
    Extract segment information from BED file.

    Returns DataFrame with:
    - n_bed_segments: total segments in BED (includes all regions)
    - n_classification_segments: collapsed parental segments (for classification)
    - segment_pattern: parental pattern string (e.g., "CL", "CLC")
    """
```

**How it works**:

1. **Read BED file**:
   ```
   read_id  start  end   segment_type
   abc123   100    500   LA4
   abc123   600    900   CA3
   ```

2. **Extract parental types**:
   - "LA4" → scan for C/L → find "L"
   - "CA3" → scan for C/L → find "C"
   - Pattern: "LC"

3. **Collapse consecutive**:
   - "LLLCC" → "LC"
   - "CLCLCL" → "CLCLCL" (no change)

4. **Count segments**:
   - `n_bed_segments` = 2 (total BED entries)
   - `n_classification_segments` = 2 (length of collapsed "LC")
   - `segment_pattern` = "LC"

## What This Tells You

### 1. Classification Accuracy
If SCO has most reads at n=2 → **Classification is working correctly!**

If there's significant spread → **Possible issues**:
- Mapping artifacts creating extra segments
- Complex rearrangements
- Ectopic recombination not fully filtered

### 2. Biological Validation
- **SCO at 2 segments** = one parental switch (CL or LC) ✓
- **NCO at 3 segments** = two switches (CLC or LCL) ✓
- **DCO at 4 segments** = three switches (CLCL or LCLC) ✓

### 3. BED vs Classification Segments

**Parental segments** = collapsed parental switches (for classification)
**BED segments** = total genomic regions in BED (may include internal splits)

Example read:
- BED: 3 entries ("LA4", "LA5", "CA3")
- Parental pattern: "LLC" → collapsed to "LC"
- Parental segments: 2 (LC → SCO)
- BED segments: 3 (original entries)

The difference shows how many internal splits/gaps exist within each parental region.
